What this investigation does not prove +

This intentionally constructed teaching example is a deterministic simulation: a scripted controller runs against synthetic data. The vulnerable version is not a bug in any real framework. It does not establish a live model’s failure rate, real procurement compliance, or external API guarantees. The repaired tool uses local SQLite transactions; real services need their own idempotency and reconciliation contracts. Recorded replay is playback, not process crash recovery. Evidence hashes detect changes relative to a trusted digest; they are not independent provenance or a tamper-proof audit.
